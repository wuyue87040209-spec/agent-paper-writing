# 考虑静态电压稳定的新能源基地构网型场站与无功源优化配置方法

## One-line thesis
以 gSCR、稳定解距离和灵敏度约束构网型场站与无功源的分层多目标配置，以提升新能源基地静态电压稳定裕度。

## Relevance to This Project
构网控制配置与无功资源配置可作为切换 CPF 外层搜索中的可控支撑变量，但论文摘要未给出 LVRT 进出事件建模。
